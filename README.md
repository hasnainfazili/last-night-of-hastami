# Last Night of Hastami (Prototype)

![Last Night of Hastami Banner](https://via.placeholder.com/1000x300.png?text=Last+Night+of+Hastami)

## 🎮 About the Prototype
**Last Night of Hastami** is an experimental prototype attempting to capture the game mechanics and feel of *Hades* by Supergiant Games. This is a work in progress, focused on testing fast-paced combat, procedural dungeons, and core gameplay mechanics.

## ⚔️ Current Features
- **Basic Combat System** – Includes melee attacks, dashing, and basic enemy AI.
- **Procedural Room Generation** – Simple randomized layouts to explore.
- **Early Weapon & Ability System** – A few prototype weapons and upgrades.
- **Placeholder Art & Sound** – Basic assets to test gameplay flow.

## 🕹️ Controls (Subject to Change)

## 🏗️ Development Status
This is a prototype built with **Unity** and **C#**. The goal is to test core mechanics before expanding further. Expect rough edges, placeholder assets, and lots of iteration.

### 📌 Requirements
